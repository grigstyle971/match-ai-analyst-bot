# ИИ-аналитик матчей — Telegram-бот

Живой бот: https://t.me/MatchAIAnalyst_bot

Три режима:
- **🔴 Лайв** (`/live`). Идущие сейчас матчи топ-лиг. Бот берёт свежую статистику: счёт, минуту, удары, владение, угловые, голы и карточки. ИИ оценивает ситуацию и предлагает идею ставки со справедливым коэффициентом («брать, если кэф ≥ X»).
- **📅 Прогнозы** (`/matches`). Ближайшие матчи АПЛ, Ла Лиги, Серии А, Бундеслиги, Лиги 1, РПЛ, ЛЧ и ЛЕ. Бот собирает таблицу, последние 5 матчей и движение коэффициентов (открытие → сейчас). ИИ даёт прогноз: вероятности рынка без маржи, свою оценку, основной исход и риски.
- **🔎 Разбор данных.** Пользователь вставляет сырую статистику, составы или коэффициенты текстом и получает структурированный разбор.

Данные о матчах берутся из публичного JSON-API ESPN (без ключа) и кэшируются: расписание на 10 минут, лайв на 45 секунд.

**Стек:** Python 3.10+, aiogram 3 (асинхронный), OpenAI SDK (работает с любым OpenAI-совместимым API).

## Надёжность

| Сбой | Что происходит |
|---|---|
| Основная модель (Gemini 3.6) не ответила за 20 с или вернула ошибку | Ответ берётся у запасной модели (Gemini 3.5) |
| Gemini недоступен целиком | Ответ даёт резервный провайдер (локальный OmniRoute) |
| ESPN не ответил | Отдаются последние удачные данные. Кэш хранится на диске и переживает перезапуск |
| ESPN режет частые запросы (403/429) | На 3 минуты бот работает только из кэша, чтобы ограничение снялось быстрее |
| ESPN недоступен, и кэша нет | Расписание, таблица и форма топ-футбола берутся из football-data.org |

Фоновая задача каждые 10 минут заранее подгружает популярные лиги.

## Структура

| Файл | Что делает |
|---|---|
| `bot.py` | Точка входа: меню, хендлеры трёх режимов, антиспам, кэш прогнозов, разбивка длинных ответов |
| `sources.py` | Загрузка расписания, таблицы, формы, коэффициентов и лайв-статистики (ESPN). Кэш, резерв, сборка «карточки матча» для ИИ |
| `backup.py` | Резервный источник статистики — football-data.org |
| `webapp.py`, `static/index.html` | Telegram Mini App: сервер с проверкой подписи Telegram и интерфейс |
| `tunnel.py` | Публичный HTTPS-адрес для Mini App через туннель Cloudflare |
| `llm.py` | Запрос к модели и понятные пользователю ошибки (ключ, лимиты, таймаут, сеть) |
| `prompts.py` | Три системных промпта: разбор данных, предматчевый прогноз, лайв-трейдинг |
| `config.py` | Настройки из `.env` |

## Запуск локально

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен.
2. Возьмите API-ключ модели. Бесплатно — Google Gemini: [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
3. Установите зависимости и заполните настройки (Windows, PowerShell):

```powershell
cd match_analyst_bot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
notepad .env
```

На macOS/Linux: `source .venv/bin/activate` и `cp .env.example .env`.

4. Запустите:

```powershell
python bot.py
```

Или двойной щелчок по `start_bot.bat`. В консоли появится `Bot started`. Откройте своего бота в Telegram, нажмите **Start** и отправьте статистику.

## Другие провайдеры моделей

Укажите в `.env` `LLM_BASE_URL` и `LLM_MODEL`:

| Провайдер | LLM_BASE_URL | LLM_MODEL |
|---|---|---|
| Google Gemini (бесплатный ключ, по умолчанию) | `https://generativelanguage.googleapis.com/v1beta/openai/` | `gemini-3.6-flash` |
| OpenAI | *(пусто)* | `gpt-4o-mini` |
| OpenRouter | `https://openrouter.ai/api/v1` | `openai/gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| OmniRoute (локально) | `http://localhost:20128/v1` | `auto` |


## Системный промпт

Полный текст — в `prompts.py`. На чём он держится:

- **Роль и аудитория.** Аналитик и лайв-трейдер, который пишет для опытных беттеров.
- **Правила мышления.** Только присланные данные, без выдумок. Коэффициенты переводятся в вероятность с учётом маржи. Малые выборки отделяются от закономерностей. Каждый вывод подкреплён цифрой.
- **Жёсткий формат.** Блоки «Тренды → Риски → Детали для беттинга → Чего не хватает» каждый раз дают одинаковую структуру.
- **Честность.** Никаких «100%» и «верняков», в конце дисклеймер 18+.
